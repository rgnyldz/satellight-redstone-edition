The SatelLight - Redstone Lamp Edition.

A ceiling lamp with Voice assistant, Presence detection, Temperature/Humidity/Pressure/Air quality readings and more. 

The parts
- ESP32-S3 development board
- Ld2420 mmwave sensor
- PCM5102 Audio DAC
- inmp441 Microphone
- BME680 sensor
- AC/DC Converter - (220V to 5V-6A)
- 5V USB speaker with 3.5mm audio jack
